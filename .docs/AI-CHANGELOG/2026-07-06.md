# Changelog 2026-07-06

## ✅ สิ่งที่ทำเสร็จ

- [core-domain] เพิ่ม CRUD สำหรับ User, Tenant และ Room พร้อมเชื่อม route เข้ากับ Express app
- [users] เพิ่มฟังก์ชันสร้าง/อัปเดตผู้ใช้แบบมี password hashing และตรวจซ้ำ email
- [tenants] เพิ่มการสร้างและอัปเดต tenant พร้อมตรวจความถูกต้องของ userId และ roomId ก่อนบันทึก
- [rooms] เพิ่มการสร้างและอัปเดตห้องพักพร้อม normalize roomNumber และป้องกันซ้ำ
- [tests] เพิ่ม regression tests สำหรับ core-domain services เพื่อยืนยัน behavior ของ user/tenant/room
- [docs] ปรับปรุงภาพรวมระบบใน `SYSTEM-BLOCK-DIAGRAM.md` ให้สะท้อนโมดูล backend ที่มีอยู่จริง และระบุว่า Socket.IO / Face Verification เป็นฟีเจอร์ในแผน
- [verification] รัน npm test สำเร็จ 19 tests / 0 failures และ npm run build สำเร็จ

## 🔧 ปัญหาที่แก้ไข

- ปิดช่องว่างในการจัดการข้อมูลหลักของระบบที่ยังขาด CRUD สำหรับ core domain
- ลดความเสี่ยงจากการสร้างผู้ใช้หรือ tenant ที่เชื่อมข้อมูลไม่ถูกต้องโดยเพิ่ม validation ขั้นพื้นฐาน
- ทำให้ระบบสามารถเริ่มเชื่อมต่อกับ billing / maintenance / notification flows ผ่านข้อมูล tenant และ room ที่มีโครงสร้างชัดเจนขึ้น

## 📋 สิ่งที่ยังค้างอยู่

- เพิ่ม seed data สำหรับ user, tenant และ room เพื่อให้ local development มีข้อมูลเริ่มต้นที่ใช้งานง่ายกว่าเดิม
- ต่อยอดความสัมพันธ์ระหว่าง users/tenants/rooms กับ billing, maintenance และ visitor flow ต่อไป
