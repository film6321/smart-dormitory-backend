# Changelog 2026-06-29

## ✅ สิ่งที่ทำเสร็จ
- **[governance]** จัดตั้งและปรับแก้กฎของ AI Agent ใน `AGENTS.md` ให้เข้ากับสถาปัตยกรรมของระบบโดยผสาน pre-task protocol และ critical code protections
- **[router]** สถาปนาแผนที่การเข้าอ่านสัญญาข้อมูลผ่าน `AI-INDEX.md` เป็นประตูเริ่มต้นของนักพัฒนาและ AI Agent
- **[docs]** พัฒนาแบบแผนทรานซิชันสถานะหอพัก (Billing, Visitor Access, Maintenance) ลงใน `.docs/ai-context/contracts/state-machine.md`
- **[docs]** ออกสัญญารูปแบบข้อมูล REST APIs และเรียลไทม์ผ่าน REST `api-contracts.md` และ Socket.IO `socket-io-contracts.md`
- **[docs]** สร้างคู่มือแนวทางความปลอดภัย, โครงสร้าง API Response, DB consistency logic (OCC / versioning), Docker network setups และ telemetry targets
- **[docs]** เพิ่มข้อตกลงโหมดการรันระบบ (Development, Staging, Production) ใน `spec-runtime-modes.md`
- **[lessons]** รวบรวมแนวคิด Enterprise Architecture และ Clean Code ตัวอย่าง TypeScript ในโมดูล backend/frontend ลงใน แฟ้มบทเรียน `Enterprise_Architecture_Lessons.md`

## 🔧 ปัญหาที่แก้ไข
- ปรับปรุงข้อตกลง WebSocket ของระบบจากเดิมในโปรเจกต์ต้นแบบที่เป็น `signalr-contracts.md` ไปเป็น `socket-io-contracts.md` เพื่อให้ตรงกับ Tech Stack ที่ผู้ใช้วางไว้จริงในฝั่ง Node.js/Express
- ตรวจพบไฟล์และโฟลเดอร์ของสัญญาที่ขาดหายไปและได้ทำการสร้างทดแทนครบถ้วนในจุดที่เหมาะสม

## 📋 สิ่งที่ยังค้างอยู่
