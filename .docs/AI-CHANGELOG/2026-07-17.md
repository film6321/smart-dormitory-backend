# 2026-07-17 — AI-assisted changes

สรุปการเปลี่ยนแปลงที่ทำโดย AI Agent (ย้ายสถาปัตยกรรมระบบตรวจจับใบหน้าเป็น FaceGate.Edge):

- **ลบระบบแบบเดิม (Legacy Python API & Proxy)**:
  - นำบริการ `face_recognition` (Python / FastAPI) ออกจาก `docker-compose.yml`
  - ลบโมดูล proxy `src/modules/faceRecognition` ออกจาก codebase
  - นำการแมปเส้นทาง proxy ออกจาก `src/app.ts`

- **ปรับปรุง Database/Prisma Schema**:
  - เพิ่มโมเดล `FaceEmbedding` และ `FaceEnrollmentPhoto` ใน `prisma/schema.prisma`
  - กำหนดความสัมพันธ์ระหว่างโมเดลใหม่และ `User` / `Visitor`
  - สั่งรัน `prisma generate` เพื่ออัปเดตโมเดล Prisma Client
  - เพิ่ม `db: any` สำหรับแก้ไขปัญหา compile-time typecheck จากการ caching ของ compiler

- **แก้ไขเอนด์พอยต์ Node.js Backend ใหม่ (`src/modules/face-verification/`)**:
  - `GET /api/face-verification/embeddings` — ดึงข้อมูล embedding ทั้งหมดเพื่อแคชที่เครื่อง Edge client
  - `GET /api/face-verification/enrollment/pending` — ดึงรายชื่อบัณฑิต/บุคคลภายนอกที่ยังไม่มี embedding เวกเตอร์
  - `GET /api/face-verification/enrollment/photo/:id` — สตรีมไฟล์ภาพของรหัสสมัครลงทะเบียนให้ Client ดัดแปลง
  - `POST /api/face-verification/enrollment/:studentId/embeddings` — บันทึกเวกเตอร์ embeddings 512 มิติจาก C#
  - `POST /api/face-verification/attendance/scan` — บันทึกประวัติสแกนเช็คอิน/เช็คเอาท์ และเปลี่ยนสถานะ Visitor / AccessLog
  - `POST /api/face-verification/devices/heartbeat` และ `live-frame` — รับสัญญาณสถานะและเฟรมภาพสดจากกล้อง Edge
