# AI Change Log — 2026-09-01

## Admin dashboard real-data and observability embed

- เปลี่ยนหน้า Admin Dashboard จากหน้าที่พึ่งพา mock/debug card ให้แสดงข้อมูลจริงจาก backend APIs ได้แก่ rooms, tenants, maintenance tickets, users และ billing
- เพิ่มการดึง bills จริงใน `DashboardContext` แล้วคำนวณ financial summary จากฐานข้อมูล:
  - ค่าเช่ารวม
  - ยอดค้างชำระ
  - รายได้สุทธิจากบิลที่ชำระแล้ว
  - series รายเดือนสำหรับกราฟยอดชำระ/ค้างชำระ
- เพิ่ม Business Health panel สำหรับแสดงอัตราเข้าพัก, ห้องที่มีผู้พัก, ห้องว่าง, นักศึกษาใช้งานอยู่, แจ้งซ่อมค้าง และผู้ใช้ออนไลน์
- เพิ่ม System Health panel สำหรับตรวจ backend health, metrics readiness, metric families และ latency check
- เพิ่ม HTTP metrics ใน backend สำหรับ Prometheus:
  - `dormitory_http_requests_total`
  - `dormitory_http_request_duration_seconds`
- เพิ่ม Grafana provisioning:
  - Prometheus datasource แบบ read-only proxy
  - dashboard provider สำหรับโหลด dashboard จากไฟล์
  - dashboard `Smart Dormitory Operations`
- ตั้งค่า Grafana ให้รองรับ iframe embedding ใน local/dev ผ่าน anonymous viewer role เท่านั้น
- ฝัง Grafana dashboard ในหน้า Admin Dashboard ด้วย iframe เพื่อให้ดูกราฟจาก Prometheus ได้ในหน้าเว็บโดยไม่ต้องเปิด Prometheus UI ตรงๆ
- ปรับ frontend env:
  - `VITE_GRAFANA_URL=http://localhost:3003`
  - `VITE_PROMETHEUS_URL=http://localhost:9091`
- แก้ปัญหา Grafana panel แสดง `No data` จาก datasource UID mismatch โดยให้ provisioning ลบ datasource เก่าและสร้างใหม่ด้วย UID คงที่ `smart_dormitory_prometheus`
- ตรวจสอบแล้ว:
  - backend build ผ่าน (`npm.cmd run build`)
  - frontend build ผ่าน (`npm run build`)
  - Grafana dashboard URL ตอบ HTTP 200
  - Prometheus ready endpoint ตอบ HTTP 200
  - Prometheus query `sum(rate(dormitory_http_requests_total[5m]))` มีข้อมูล
  - Grafana datasource proxy query ไปยัง Prometheus มีข้อมูล

## Maintenance and admin usability follow-up

- เพิ่ม endpoint ลบ maintenance ticket สำหรับ ADMIN: `DELETE /api/maintenance/:id`
- เพิ่มปุ่มลบใน MaintenanceCard พร้อม confirm ก่อนลบและ refresh รายการหลังสำเร็จ
- ปรับ error message ฝั่ง frontend ให้แสดง HTTP status/message จริงเมื่อลบหรืออัปเดตสถานะไม่สำเร็จ
- เพิ่ม handling Prisma `P2025` ให้ตอบ `404 Maintenance ticket not found` แทน `500 Internal Server Error`
- เพิ่มระบบจุดแดงแจ้งเตือนรายการแจ้งซ่อมใหม่ โดยจุดแดงหายเมื่อ admin กดเปิดดูกลุ่มหรือรายการนั้น
- ปรับกล่องวันเวลาที่สะดวกให้ช่างเข้ามาดำเนินการจากสีเหลืองเป็นสีเทาอ่อน
- เพิ่มปุ่มออกจากระบบใน Admin Dashboard sidebar โดยเรียก `AuthContext.logout()` และ redirect ไป `/login`
