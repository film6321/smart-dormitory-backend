# Changelog 2026-07-10

## ✅ สิ่งที่ทำเสร็จ

- [repo] สร้าง/ปรับปรุง repository layer สำหรับโมดูลหลัก (users, auth, notifications) เพื่อแยก Prisma calls ออกจาก Service
- [service] ปรับ `NotificationService` ให้เรียกเมธอดแบบ static ของ `NotificationRepository` และเพิ่ม `getDb()` คืนค่า `prisma as any`
- [repo] ปรับ `users.repository.ts` และ `auth.repository.ts` ให้ cast Prisma client เป็น `any` ภายในเมธอดเพื่อลด TypeScript noise ชั่วคราว
- [tests] เตรียมการรัน `npm run test:typecheck` หลังรีเจน Prisma client

## 🔧 ปัญหาที่แก้ไข

- แยกความรับผิดชอบ: ลดการเรียก Prisma ตรงจาก Service โดยย้ายไปยัง Repository
- แก้ปัญหา mismatch ระหว่างการเรียกเมธอด instance vs static ใน `NotificationService` / `NotificationRepository`

## 📋 สิ่งที่ยังค้างอยู่

- รัน `npx prisma generate` และ `npm run test:typecheck` เพื่อยืนยันว่า Prisma Client types เป็นปัจจุบันและไม่มี error ที่เหลือ
- ปรับ payload create/update ให้เป็น Prisma input shapes (`connect` สำหรับความสัมพันธ์) แทนการใช้ `any` เมื่อพบจุดที่ TypeScript แจ้งเตือน
- ตรวจสอบ repository อื่นที่เพิ่งสร้าง (billing, ocr, tenants, visitors ฯลฯ) ให้สอดคล้องกับ pattern เดียวกัน
