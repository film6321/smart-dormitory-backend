## 2. Face Recognition Multi-face Workflow & Backend Integration

- **Backend Wrapper Integration:** ปรับปรุง `face-verification.service.ts` ใน Backend ให้ส่งคำขอลงทะเบียนใบหน้า (`POST /api/v1/faces/register`) และตรวจสอบใบหน้า (`POST /api/v1/faces/verify`) ไปยัง Python FastAPI Face Recognition Service โดยตรง
- **Security Guardrail (Denial-by-Default):** ปรับ Mock Fallback ของระบบตรวจสอบใบหน้าให้ปฏิเสธการผ่านเสมอ (`match: false`) กรณีเซิร์ฟเวอร์ AI ภายนอกไม่พร้อมใช้งาน เพื่อความปลอดภัยสูงสุด
- **Frontend Multi-face Prioritization (`MonitorPage.tsx`):**
  - รองรับการตรวจจับใบหน้าหลายคนในเฟรมกล้องพร้อมกัน
  - คำนวณขนาด Bounding Box เพื่อจัดลำดับประมวลผลใบหน้าที่ **ใกล้กล้องที่สุดก่อน**
  - ทำการ Crop ตัดภาพเฉพาะกรอบใบหน้าก่อนส่งไปประมวลผล ช่วยเพิ่มความแม่นยำและลดขนาด Payload
  - แสดงผลกล่องสถานะแบบ Real-time: กรอบเขียวสำหรับผู้มีสิทธิ์ในระบบ และกรอบแดงสำหรับบุคคลที่ไม่พบข้อมูลในฐานข้อมูล
