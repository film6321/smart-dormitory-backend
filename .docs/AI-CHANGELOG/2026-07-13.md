# 2026-07-13 — AI-assisted changes

สรุปการเปลี่ยนแปลงที่ทำโดย AI Agent (คู่มือการทำงาน):

- แก้ไขระบบแจ้งเตือน (`NotificationService` / `NotificationRepository`)
  - ทำให้ `notificationAuditLog` และ `notificationDeadLetter` ทนต่อ mocked DB ใน unit tests (no-op / fallback)
  - ปรับ API ของ `NotificationService` ให้รองรับการฉีด `db` (dependency injection) เพื่อความสามารถในการทดสอบ
  - แก้ไข unit tests ที่เกี่ยวข้อง — ตอนนี้ backend tests ผ่านทั้งหมด (27/27)

- ปรับปรุงรูปแบบการฉีด `db` ข้ามชั้น Repository ↔ Service
  - บริการหลัก (Users, Tenants, Rooms, ... ) รองรับการส่ง `db` เป็นพารามิเตอร์ เพื่อให้สามารถใช้ fake prisma/mocks ได้ง่ายขึ้น
  - แทนที่การใช้ `as any` ด้วยชนิด Prisma input ที่เหมาะสม (connect/disconnect สำหรับความสัมพันธ์)

- เพิ่ม Metrics ในบริการ Face_Recognition (FastAPI)
  - เพิ่ม `/metrics` endpoint ด้วย `prometheus_client` (Counter + Histogram)
  - เพิ่ม middleware เก็บ request count และ latency
  - ติดตั้ง dependency `prometheus-client` และอัปเดต `requirements.txt`
  - แก้ไข `app/database/postgres.py` ให้เลือกใช้ `postgresql+asyncpg://` เมื่อเป็นไปได้ (SQLAlchemy asyncio requirement)
  - รันชุดทดสอบของ Face_Recognition ใน virtualenv — tests ที่เกี่ยวข้องผ่านแล้ว (8/8)

- อื่น ๆ
