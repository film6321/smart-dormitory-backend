# Changelog 2026-09-06

## ✅ สิ่งที่ทำเสร็จ

### Multi-bill PaymentBatch

- เพิ่ม `PaymentBatch` และ `PaymentBatchItem` สำหรับรวมหลาย Bill เป็นการชำระเงินเดียว
- เพิ่มรายละเอียด Bill: `rentAmount`, `electricAmount`, `waterAmount`, `penaltyAmount`
- เพิ่ม API สร้าง batch, รายละเอียด/status, QR และ upload slip
- เพิ่มการตรวจ owner, idempotency, SHA-256 slip hash, OCC และ transaction สำหรับอัปเดตหลาย Bill
- เพิ่มการ persist ค่าใช้จ่ายแยกสำหรับบิลที่สร้างใหม่
- เพิ่ม frontend flow เลือกบิลหลายรายการ, รวมยอด, รายละเอียด, QR, upload slip, polling และผลลัพธ์สำเร็จ/ล้มเหลว

## 🔧 ปัญหาที่แก้ไข

- ไม่ให้ frontend กำหนดยอดรวมเอง: backend คำนวณจาก Bill ที่ user เป็นเจ้าของเท่านั้น
- ไม่ hardcode ข้อมูลบัญชีใน frontend: frontend รับข้อมูลบัญชีจาก backend config

## 📋 สิ่งที่ยังค้างอยู่

- ต้องทดสอบ PaymentBatch ด้วย Bill จริงและ Thunder API key/application ที่ใช้งานได้
- Thunder ยังไม่มี status polling/webhook ที่ตรวจพบจาก paymentProject ปัจจุบัน จึงใช้ upload slip เป็นตัวกระตุ้นการตรวจ
- Backend test มี Face Verification failure เดิม 1 รายการ ไม่เกี่ยวกับ PaymentBatch
