# Changelog 2026-09-05

## ✅ สิ่งที่ทำเสร็จ

### Backend Payment Integration

- เพิ่ม `Payment` model และ migration ที่ผูกกับ `Bill` และ `User`
- เพิ่มสถานะ `PENDING`, `VERIFYING`, `PAID`, `FAILED` และ `MANUAL_REVIEW`
- เพิ่ม idempotency ด้วย `idempotencyKey`, SHA-256 `slipHash` และ `providerTransactionId`
- เพิ่ม migration reconcile สำหรับ Tenant schema drift โดยไม่ reset หรือลบข้อมูลเดิม
- เพิ่ม `PaymentProviderClient` สำหรับเรียก `paymentProject` ผ่าน `PAYMENT_API_URL` ที่ port `8002`
- เพิ่ม timeout configuration ผ่าน `PAYMENT_API_TIMEOUT_MS`
- ปรับ `POST /api/billing/:id/upload-slip` และ alias ให้รับ `slipImage`
- เพิ่มการตรวจ owner ของ Bill, idempotency, duplicate slip และ OCC
- กำหนดยอดไม่ตรงกับ Bill หรือบัญชีผู้รับไม่ตรงเป็น `FAILED`
- เพิ่ม `GET /api/billing/:id/payment-qr` โดยอ่านยอดจาก `Bill.amount` ฝั่ง backend เท่านั้น

### Frontend Payment Integration

- เพิ่มหน้า `/student/billing` สำหรับดูบิลและสถานะการชำระเงิน
- เพิ่มการแสดง PromptPay QR และการ upload slip พร้อม `Idempotency-Key`
- เพิ่มเมนูค่าใช้จ่ายและการชำระเงินในหน้า Student Home
- เพิ่มสถานะ `UNPAID`, `OVERDUE`, `VERIFYING`, `PAID` และ `FAILED`

## 🔧 ปัญหาที่แก้ไข

- ป้องกันการใช้ payment port `8000` ซึ่งเป็น port ที่ระบบใช้เชื่อม OCR อยู่แล้ว
- ย้าย payment API ไปใช้ port `8002`
- ทำให้ backend container ติดต่อ payment API ผ่าน `host.docker.internal:8002`
- แก้ schema drift โดยไม่ใช้ `prisma migrate reset` และไม่ลบข้อมูลเดิม
