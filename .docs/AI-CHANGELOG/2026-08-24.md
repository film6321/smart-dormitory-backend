# Changelog 2026-08-24

## Maintenance Image Viewer & Interactive Lightbox Enhancements

### สิ่งที่ทำเสร็จ

- **[frontend-zoom]** พัฒนาปุ่มปรับขนาดซูม (Zoom Slider & Buttons) ควบคุมความละเอียดขนาดรูปภาพรูปแจ้งซ่อมได้ละเอียด 100% - 400% (1x - 4x) พร้อมแสดงสถานะเปอร์เซ็นต์
- **[frontend-panning]** เพิ่มระบบคลิกลากเมาส์เลื่อนพิกัด (Drag-to-pan) และนิ้วปัดเลื่อนบนมือถือเมื่อรูปมีขนาดขยายใหญ่กว่าพื้นที่แสดงผล (Scale > 100%)
- **[frontend-ux-lock]** แก้ไขปัญหาคลิกลากแล้วรูปดีดพิกัดกลับสู่ศูนย์ (Click-vs-drag collision) โดยเพิ่มการเช็ค displacement distance >= 5px เพื่อแยกแยะการกดซูมเดี่ยวออกจากการลากจอ
- **[frontend-scroll-blocking]** แก้ไขอาการหน้าหลัง (Background page/modal) เลื่อนหมุนตามขณะเลื่อนเมาส์ดึงภาพ:
  - ใช้ `useEffect` ล็อกบอดี้ของ HTML บราวเซอร์เป็น `overflow = 'hidden'` ระหว่างวิดจเปิดขยายภาพ
  - ใช้ React `ref` ผูก `wheel` และ `touchmove` ในโหมด active `{ passive: false }` เพื่อเบรกคำสั่ง default scroll บับเบิ้ลของเว็บเบราว์เซอร์อย่างเด็ดขาด
- **[frontend-ui]** ดีไซน์สไตล์มินิมัลใน CSS Module: ปลดกล่องมืดและกรอบสีดำเหลี่ยม (panel outline) วาดภาพแบบลอยเด่นใสซ้อนบนกระจกฝ้าพื้นหลัง `rgba(0, 0, 0, 0.75)` กรองความนุ่มด้วย `backdrop-filter: blur(6px)` พร้อมสาดมิติเงานิ่ม `drop-shadow` รอบนอกสลิปภาพจริง

### การตรวจสอบ

- Frontend build ผ่าน
- TypeScript diagnostics ของ MaintenanceCard JSX และ CSS Module ผ่านหมดจด ไม่มีข้อผิดพลาด
- พิกัดการสะท้อนของ dragging และการป้องกัน double scrolling ทำงานเสถียรบน PC และ Mobile Viewport
