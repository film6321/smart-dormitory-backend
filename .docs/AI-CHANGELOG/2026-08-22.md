## OCR identity fields and age calculation

### สิ่งที่ทำเสร็จ

- [ocr] เพิ่ม mapping ที่อยู่จาก OCR รองรับ `address`, `address_th` และ `th_address`
- [ocr] ส่งเลขบัตรประชาชนที่ normalize เป็นตัวเลขเต็มใน authenticated application upload response เพื่อใช้เติมข้อมูลสัญญาของเจ้าของใบสมัคร
- [security] ตารางผล OCR ยังคงเก็บ `citizenIdMasked` และ `citizenIdHash` ไม่เปิดเลขเต็มในรายการตรวจสอบทั่วไป
- [tenant] ข้อมูล `ocrData.citizenId` และ `ocrData.address` ถูกส่งต่อไปเก็บใน `Tenant.citizenId` และ `Tenant.address`
- [contract] คำนวณอายุปัจจุบันจาก `birthDateTh` รองรับปี พ.ศ. และใช้ค่าอายุในข้อมูลสัญญาแทนค่า default 20

### การตรวจสอบ

- Backend build ผ่าน
- Backend tests ผ่าน 32 tests
- Frontend build ผ่าน
- TypeScript diagnostics ของ OCR, tenant controller และ contract review ไม่พบ error

## OCR connectivity and false-success status fix

### สิ่งที่ทำเสร็จ

- [ocr] แก้ Docker backend จาก `localhost:8000` เป็น `host.docker.internal:8000` พร้อม `host-gateway` mapping เพื่อให้เรียก OCR service ที่รันบน Windows host ได้
- [tenant-upload] ถ้า OCR service unavailable ให้ `POST /api/tenants/upload-documents` ตอบ `502` แทนการตอบสำเร็จพร้อม `ocrData: null`
- [tenant-upload] ถ้า OCR อ่านภาพได้แต่ยืนยันว่าไม่ใช่บัตรประชาชนไทย ให้ตอบ `422` และไม่ประกาศว่าเอกสาร verified
- [frontend] แก้ badge ใน Step 4 ให้แสดงผ่านเฉพาะเมื่อ `ocrData.isThaiIdCard === true`; กรณีอื่นแสดงว่ารอผล OCR

### การตรวจสอบ

- ตรวจ Windows host port 8000 พบ OCR service เปิดอยู่
- ตรวจจาก backend container ไป `http://host.docker.internal:8000` ได้ HTTP 200
- `docker compose config --quiet` ผ่าน
- Backend build ผ่านและ backend tests ผ่าน
- Frontend build ผ่าน
