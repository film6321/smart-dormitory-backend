# Changelog 2026-09-21

## สิ่งที่ทำเสร็จ

- **[tenants / ocr]** ปรับปรุงระบบตรวจสอบ OCR บัตรประชาชน และระบบตรวจสอบเอกสารสัญญาในขั้นตอนสมัครเข้าหอพักของนักศึกษา:
  - **Permissive Field Fallback with Boundary Validation:**
    - กรณีภาพ **ไม่ใช่บัตรประชาชน** (`idDetected: false`): ปฏิเสธทันทีด้วย HTTP 422 (`ภาพนี้ไม่ผ่านการตรวจว่าเป็นบัตรประชาชน กรุณาอัปโหลดบัตรประชาชนใหม่`)
    - กรณีเป็นบัตรประชาชนแต่บางฟิลด์อ่านไม่ได้ (เช่น checksum ผิด, ที่อยู่/วันเกิดอ่านไม่ชัด): ให้ผ่านการอัปโหลดได้ โดยส่งฟิลด์ที่อ่านไม่ได้ออกไปเป็นค่าว่าง (`""`) เพื่อให้นักศึกษากรอกเพิ่มเติมในฟอร์ม
    - กรณีเป็นบัตรประชาชนที่อ่านได้ครบถ้วนสมบูรณ์: ให้ผ่านและส่งข้อมูลครบถ้วนทั้งหมด (`citizenId`, `fullNameTh`, `birthDateTh`, `age`, `address`)
  - **Strict Placeholder & Sentinel Value Sanitization:**
    - ปรับปรุง `isFilledText` ใน `tenants.dto.ts` เพื่อตรวจจับและสกัดกั้นค่าว่าง, ช่องว่างเปล่า (whitespace), เครื่องหมายขีดลบ (`-`, `–`, `—`), ดอกจัน (`*`), Underscore (`_`), และ Placeholder เช่น `"N/A"`, `"null"`, `"undefined"`, `"none"`
    - บังคับใช้ใน `validateHousingApplication` เพื่อป้องกันการส่งเอกสาร/สัญญาหากมีฟิลด์สำคัญใดยังไม่ได้กรอกหรือมีเครื่องหมาย `-`
- **[testing]** เพิ่ม Unit Tests ครอบคลุมทั้ง 3 สถานการณ์ของ OCR (ไม่ใช่บัตร, บัตรที่มีฟิลด์บางส่วน, บัตรที่สมบูรณ์) และการป้องกันการส่งเอกสารที่มีค่าว่างหรือ `-` ใน `tests/unit/housing-ocr-flow.test.ts`
