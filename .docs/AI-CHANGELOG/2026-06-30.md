# Changelog 2026-06-30

## ✅ สิ่งที่ทำเสร็จ

- แก้ไขปัญหา Prisma migration ที่เชื่อมต่อฐานข้อมูลไม่ถูกต้องโดยปรับ `DATABASE_URL` ใน `.env` จาก `localhost:5432` เป็น `localhost:5433`
- ลบ migration ที่ล้มเหลว `20260629192750_add_core_dormitory_models` ออกจากโฟลเดอร์ `prisma/migrations`
- ยืนยันสถานะ Prisma migration ว่า `Database schema is up to date`
- เตรียมฐานข้อมูลและ schema สำหรับโมดูล backend ถัดไปเรียบร้อย
- เพิ่ม validation middleware สำหรับโมดูล billing, maintenance และ visitor เพื่อรองรับ payload ที่เข้ามาจาก frontend
- เชื่อม route สำหรับ billing, maintenance และ visitor เข้ากับระบบตรวจสอบสิทธิ์ admin และ shared error handling
- ยืนยันว่า backend build และ automated tests ผ่านเรียบร้อยด้วย `npm run build` และ `npm test`

## 🔧 ปัญหาที่แก้ไข

- พบค่า `DATABASE_URL` ไม่ตรงกับ Docker Compose database port
- เหตุการณ์ Prisma สร้าง shadow migration ล้มเหลว เนื่องจากฐานข้อมูลยังไม่พร้อมหรือมี drift
- ปัญหา validation decorators กับ TypeScript runtime ถูกแก้ด้วยการใช้ middleware แบบ schema-based ที่เข้ากันได้กับ build pipeline

## 📋 สถานะปัจจุบัน

- โมดูล billing, maintenance และ visitor มี route / service / validation เริ่มทำงานได้แล้ว
- ระบบยังคงต้องต่อยอดไปสู่การเชื่อม OCR สำหรับ slip upload และเพิ่ม business logic ที่ลึกขึ้นในอนาคต
