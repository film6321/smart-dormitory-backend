# Changelog 2026-09-11

## สิ่งที่ทำเสร็จ

- [auth] บังคับการสมัครสมาชิกทั่วไปให้ใช้ role `STUDENT` จาก Backend และไม่รับ role จาก Frontend
- [auth] คง `password: true` เฉพาะ query ที่ใช้ตรวจ Login และเอา password hash ออกจากผลลัพธ์ `createUser`
- [users] ปรับ User model usage ให้สอดคล้องกับ schema ที่ไม่มี `firstName` และ `lastName`
- [users] ลด User existence queries ให้เลือกเฉพาะ `id`
- [rooms] เอา `tenants` และ `bills` ที่ไม่จำเป็นออกจาก room list/detail queries
- [billing] กรอง payment responses ไม่ให้ส่ง `providerResponse`, `slipPath`, `slipHash` และ `idempotencyKey` ออกทาง HTTP
- [tenants] ใช้ `Tenant.fullName`, `username` หรือ `email` แทน `firstName`/`lastName`
- [documents] จำกัดการเข้าถึงเอกสารและรูปภาพ ตรวจ path ป้องกัน path traversal และ mask เลขบัตรประชาชนใน upload response
- [maintenance] จำกัด endpoint ดาวน์โหลดรูป Maintenance ให้ Admin ที่ผ่าน authentication
- [logging] เปลี่ยน access log จาก `req.originalUrl` เป็น `req.path` เพื่อไม่เก็บ query string ที่อาจมีข้อมูลลับ

## ปัญหาที่แก้ไข

- แก้ TypeScript contract ของ `AuthRepository.createUser` ให้รับ password hash สำหรับบันทึก แต่ไม่คืน hash กลับ response
- แก้ query ที่ดึง User หรือ relation มากเกินจำเป็น
- แก้ duplicate registration call ใน AuthController ที่อาจสร้างบัญชีซ้ำ
- แก้การอ้าง `User.phone` ให้ใช้ `Tenant.phone` ใน Notification flow
- แก้ query room lookup ใน `index.ts` ให้ใช้ Prisma client และคืนเลขห้องของ tenant ที่ตรงกับ user

## สิ่งที่ยังค้างอยู่

- ตรวจและปรับ fallback secret ของ Face Verification ให้ไม่ใช้ค่า hard-coded ใน production
