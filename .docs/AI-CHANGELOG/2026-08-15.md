- Configured local development paths in `.env` (`UPLOAD_ROOT=./uploads/private`) and unified the OCR API endpoints.

### 4. Admin Dashboard Data Sync
- Modified `normalizeTenant` mapping function inside `DashboardContext.tsx` on the frontend to map real DB model fields:
  - `fullName` -> maps to `name`
  - `phone` -> maps to `contact`
  - `yearLevel` -> maps to `year`
  - Normalizes uppercase statuses (e.g., `PENDING` -> `Pending`) to ensure the Admin list table correctly styles active/pending warning badges.
  - Falls back to `preferredRoomType` when a room number has not yet been assigned by the administrator.
