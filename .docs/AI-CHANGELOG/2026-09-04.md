# AI Change Log — 2026-09-04

## 1. Billing Management Module — Automatic Utility Bill Generation

### Overview
สร้างระบบจัดการบิลค่าน้ำค่าไฟอัตโนมัติในหน้า Admin โดยรองรับการกรอกหน่วยไฟและคำนวณค่าใช้จ่ายแบ่งตามจำนวนผู้เช่าจริงในห้อง

### Backend Changes (`smart-dormitory-backend`)

#### `src/modules/billing/billing.repository.ts`
- เพิ่ม `findRoomByNumberWithTenants(roomNumber: string)` — query ห้องพร้อม tenants (status ACTIVE) และ `rentalContract` สำหรับดึงค่าเช่าจากสัญญา
- เพิ่ม `createBills(data: Prisma.BillUncheckedCreateInput[])` — batch insert บิลหลายรายการพร้อมกัน
- เพิ่ม `deleteBill(id: string)` — ลบบิลรายการเดียว

#### `src/modules/billing/billing.service.ts`
- เพิ่ม `getRoomBillingInfo(roomNumber: string)` — ส่งคืนข้อมูลห้อง, ผู้เช่า Active, และค่าเช่าสำหรับ Preview ก่อนออกบิล
- เพิ่ม `generateRoomBills(dto)` — สร้างบิลให้ผู้เช่าทุกคนในห้อง โดย:
  - คำนวณค่าไฟ = `electricUnits × 8 บาท/หน่วย`
  - ค่าน้ำ = `100 บาท/ห้อง` (อัตราคงที่ตามสัญญา)
  - แบ่ง = `(ค่าเช่า + ค่าไฟรวม + ค่าน้ำ) / จำนวนผู้เช่า Active จริง`
  - กัน edge case: ห้องว่าง (0 คน) ระบบจะ return error ไม่สร้างบิล
- เพิ่ม `deleteBill(id: string)` — ลบบิลพร้อม check not found (Prisma P2025)

#### `src/modules/billing/billing.dto.ts`
- เพิ่ม `generateRoomBillSchema` — validate `roomNumber`, `electricUnits` (positive number), `month` (1–12), `year`, `dueDate` (optional ISO string)

#### `src/modules/billing/billing.controller.ts`
- เพิ่ม `getRoomBillingInfo` — `GET /room-info/:roomNumber`
- เพิ่ม `generateRoomBills` — `POST /generate-room-bill`
- เพิ่ม `deleteBill` — `DELETE /:id`
- ทุก endpoint ใช้ `ApiResponse<T>` wrapper ตามมาตรฐาน

#### `src/modules/billing/billing.routes.ts`
- ลงทะเบียน 3 route ใหม่:
  - `GET /api/billing/room-info/:roomNumber` (ADMIN auth)
  - `POST /api/billing/generate-room-bill` (ADMIN auth)
  - `DELETE /api/billing/:id` (ADMIN auth)

### Frontend Changes (`smart-dormitory-frontend`)

#### `src/services/adminApi.ts`
- เพิ่ม `getRoomBillingInfo(roomNumber)` — GET room info with tenants
- เพิ่ม `generateRoomBill(dto)` — POST generate bills for a room
- เพิ่ม `deleteBill(id)` — DELETE a bill by ID

#### `src/componants/addminpage/layouts/DashboardLayout.tsx`
- เปลี่ยนชื่อ menu item จาก "รายรับ-รายจ่าย" เป็น **"จัดการบิล / ค่าน้ำค่าไฟ"** พร้อมเปลี่ยน icon เป็น `Receipt`

#### `src/componants/addminpage/pages/Income-and-Expenses/IncomeAndExpensesPage.tsx`
- ออกแบบหน้าใหม่ทั้งหมด (clear หน้าเดิม) เป็นหน้าจัดการบิลสมบูรณ์ ประกอบด้วย:
  - **Summary Cards:** แสดงสถิติบิล (รอชำระ, กำลังตรวจสอบ, ชำระแล้ว, เกินกำหนด)
  - **Quick Bill Generator:** ฟอร์มกรอกเลขห้อง / หน่วยไฟ / เดือน-ปี พร้อม Live Preview ค่าใช้จ่ายก่อนออกบิล
  - **Bill Table:** ตารางรายการบิลทั้งหมด พร้อม filter สถานะ / เดือน และปุ่มลบ
  - **Monthly Tabs:** เลือกดูประวัติแยกตามเดือน

#### `src/componants/addminpage/pages/Income-and-Expenses/IncomeAndExpensesPage.module.css`
- เขียน CSS ใหม่ด้วยธีม Dark glassmorphism: gradient cards, hover effects, smooth transitions

- อัตราน้ำ: **100 บาท/ห้อง** (fixed by contract)
- แบ่งบิล: **หารตามจำนวน Active tenants จริง** (ไม่ใช่ capacity สูงสุดของห้อง)

## 3. Student Contract & Document Details Modal Popup for Admin

### Overview
ปรับปรุงหน้าจัดการข้อมูลนักศึกษาในฝั่ง Admin (`StudentsPage.tsx`) โดยเมื่อคลิกปุ่ม **"ดูข้อมูล"** ในตาราง จะเปิดหน้าต่าง **Modal Popup with Overlay Backdrop** (แบบเดียวกับหน้าต่างคำขอแจ้งซ่อมบำรุง) แสดงข้อมูลสัญญาเช่า เอกสารแนบ (บัตรประชาชน + สลิปโอนเงิน) และข้อมูลผู้สมัครอย่างละเอียด

### Backend Changes (`smart-dormitory-backend`)
- `tenants.controller.ts`: เพิ่มเมธอด `getTenantDocumentById` สำหรับดึงไฟล์เอกสารแนบ (`id-card` หรือ `payment-slip`) ของผู้เช่าแต่ละคน
- `tenants.routes.ts`: เพิ่ม Route `GET /api/tenants/:id/documents/:documentType` คุ้มครองสิทธิ์ด้วย `verifyToken` และ `requireRole(['ADMIN'])`

### Frontend Changes (`smart-dormitory-frontend`)
- `adminApi.ts`: เพิ่มฟังก์ชัน `getTenantDocumentById(id, documentType)` ดึงไฟล์แบบ blob
- สร้างคอมโพเนนต์ใหม่ `StudentDocumentModal`:
  - **Header:** แสดงชื่อนักศึกษา, รหัสนักศึกษา, ห้องพัก, สถานะ พร้อมปุ่มปิด `✕`
  - **Tab 1 — หนังสือสัญญาเช่าหอพัก:** เอกสารทางการครบถ้วน (ผู้ให้เช่า, ผู้เช่า, ห้องพัก, ค่าเช่า, เงินมัดจำ, ค่าน้ำ-ค่าไฟ 8 บาท/หน่วย และลายมือชื่อ)
  - **Tab 2 — เอกสารแนบหลักฐาน:** พรีวิวรูปบัตรประชาชน (พร้อมข้อมูล OCR) และสลิปโอนเงินมัดจำ รองรับคลิกขยายภาพ Lightbox Zoom
  - **Tab 3 — ข้อมูลผู้สมัคร:** ข้อมูลส่วนตัว, หลักสูตร, ชั้นปี, ข้อมูลผู้ติดต่อฉุกเฉิน
  - **Footer Actions:** ปุ่ม อนุมัติคำขอ / ปฏิเสธ / ยกเลิกการอนุมัติ, ปุ่ม พิมพ์ / บันทึก PDF, และปุ่ม ปิดหน้าต่าง
- `StudentsPage.tsx`: เชื่อมต่อ Modal แทนที่แผงข้อความเดิมด้านบน ล็อค Scroll พื้นหลังขณะเปิด Modal
