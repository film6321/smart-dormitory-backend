# Changelog 2026-09-25

## สิ่งที่ทำเสร็จ

- **[visitor / ocr]** ปรับปรุงระบบลงทะเบียนผู้มาติดต่อ (Visitor Registration) และเชื่อมโยง OCR บัตรประชาชน (OCR-First Flow):
  - **Endpoint & Routing Alignment (แก้ไขปัญหา 404 Not Found):**
    - เพิ่ม Route Aliases ใน `src/modules/ocr/ocr.routes.ts`: `POST /identity-card`, `POST /id-card`, `POST /idcard`, `POST /jobs` เพื่อรองรับคำขอจาก Frontend ทุกรูปแบบ
    - เพิ่ม Route Aliases ใน `src/app.ts`: `app.use('/ocr', ocrRoutes)` และ `app.use('/visitor', visitorRoutes)` ป้องกัน 404 เมื่อเรียกโดยไม่มี prefix `/api`
    - ติดตั้ง Multer Upload Handler (`uploadIdCardImage`) ให้กับ `src/modules/visitor/visitor.routes.ts` เพื่อรองรับทั้ง Multipart Form Data (`file`, `image`, `idCard`, `document`) และ JSON `{ imageBase64 }`
    - เพิ่ม Route Aliases ใน `visitor.routes.ts`: `POST /verify-id-card`, `POST /verify`, `GET /:id`
  - **Visitor Service & Controller Hardening:**
    - ปรับปรุง `VisitorController.scanVisitorIdCard` ให้แปลงไฟล์อัปโหลดเป็น base64 Data URL ส่งต่อให้ `VisitorService.scanVisitorIdCard` และ `OcrService.verifyIdCard` ได้อย่างสมบูรณ์
    - ปรับปรุง `VisitorService.registerVisitor` ให้รองรับการค้นหาห้องพักอัตโนมัติจาก `roomNumber` (เช่น `"301"` หรือ `"ห้อง 301"`) และผูกข้อมูลผู้เช่าจาก `tenantName`
    - ปรับปรุง `visitor.dto.ts` ให้ยืดหยุ่นรองรับ `roomNumber` และ `tenantName`
  - **Zero Any & Strict Type-Safety:**
    - รักษากฎ Zero Any และ TypeScript Strictness ทั่วทั้งระบบ
    - อัปเดต Frontend Component ให้ใช้ `axios.isAxiosError` Type Guard แทน `catch (err: any)`
- **[testing]** 
  - เพิ่ม Unit Test สำหรับ Room resolution จาก `roomNumber` string ใน `tests/unit/visitor-flow.test.ts`
  - อัปเดตและขยาย Test Coverage สำหรับ Visitor Route Aliases ใน `tests/unit/route-aliases.test.ts` และ `tests/unit/route-aliases-additional.test.ts`
