# Changelog 2026-09-20

## สิ่งที่ทำเสร็จ

- **[face-verification]** แก้ไขปัญหาการสแกนใบหน้าติดซ้ำ 2–3 ครั้งใน 1 รอบ, อาการระบุตัวตนผิดพลาด, และเพิ่มฟังก์ชันเคลียร์ประวัติสแกน:
  - **Distributed Cooldown Lock:** เพิ่ม `acquireCooldownLock` ใน `FaceVerificationService` ด้วยกรอบเวลา Cooldown 5 วินาทีต่อบุคคลและอุปกรณ์ (`lock:face-cooldown:*`) เพื่อป้องกันการสร้าง `AccessLog` และการยิง Event ซ้ำซ้อนเมื่อกล้องส่งเฟรมภาพเข้ามาติดต่อกัน
  - **Strict Threshold Guardrail:** กำหนดค่า `DEFAULT_SIMILARITY_THRESHOLD = 0.68` (และรองรับการปรับผ่าน `FACE_SIMILARITY_THRESHOLD` env) พร้อมเพิ่ม Guardrail ตรวจสอบความเหมือนก่อนยืนยันตัวตน เพื่อป้องกันอาการหลงเป็น Admin หรือบุคคลอื่นเมื่อความคมชัดหรือคะแนนความเหมือนต่ำกว่าเกณฑ์ความปลอดภัย
  - **Log Consolidation & Deduplication:** ขจัด Double Logging (ลบ `FACE_VERIFY` ซ้ำซ้อนที่บันทึกชนกับ `FACE_GATE` ใน controller) และปรับปรุง query ใน `scanHistory` ให้ดึงเฉพาะ `FACE_GATE` เพื่อให้ประวัติการเข้า-ออกตรงกับจำนวนครั้งการเดินผ่านจริง 1:1
  - **Clear Scan History:** เพิ่มเมธอด `clearScanHistory` ใน `FaceVerificationMonitoringBus` และ Controller พร้อมเปิด Endpoint `DELETE /face-verification/scan-history` และ `POST /face-verification/scan-history/clear` เพื่อให้ Admin สามารถล้างประวัติการสแกนสดและฐานข้อมูล AccessLog ได้ทันทีพร้อมกระจายสัญญาณ SSE รีเซ็ตหน้าจอ Dashboard
- **[testing]** เพิ่ม Unit Tests ครอบคลุมกลไก Cooldown Lock, Strict Threshold Guardrail, และ Clear Scan History ใน `tests/unit/face-verification.test.ts`
