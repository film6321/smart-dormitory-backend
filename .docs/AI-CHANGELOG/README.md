# AI-CHANGELOG

โฟลเดอร์นี้ใช้สำหรับเก็บบันทึกการเปลี่ยนแปลงที่ AI Agent หรือทีมพัฒนาดำเนินการในแต่ละวัน

## รูปแบบการตั้งชื่อไฟล์
```
YYYY-MM-DD.md
```

## รูปแบบเนื้อหาภายในแต่ละไฟล์
```markdown
# Changelog YYYY-MM-DD

## ✅ สิ่งที่ทำเสร็จ
- [module] รายละเอียดสิ่งที่เปลี่ยนแปลง

## 🔧 ปัญหาที่แก้ไข
- รายละเอียดปัญหา + วิธีแก้

## 📋 สิ่งที่ยังค้างอยู่
- รายการที่ยังต้องทำต่อ
```

## กฎการใช้งาน
* **Append-only:** ห้ามแก้ไขหรือลบ entry เก่า เพิ่มได้อย่างเดียว
* **ต้องขอ Confirm จาก Dev ก่อนเขียน:** AI Agent ห้ามเขียน changelog โดยอัตโนมัติ
* **อ่านเฉพาะวันที่จำเป็น:** ห้ามโหลดทุกไฟล์พร้อมกัน (Token Window)
