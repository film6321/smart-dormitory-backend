# 2026-08-06 — AI-assisted changes

สรุปการเปลี่ยนแปลงที่ทำโดย AI Agent (Face Recognition Environment & MediaPipe Debugging):

## ✅ สิ่งที่ทำเสร็จ

- **[Face_Recognition] สร้างสภาพแวดล้อมสตรีมกล้อง (.venv) ใหม่** — ย้ายการประมวลผลจากสภาพแวดล้อม Python 3.14.0 (Pre-release) ที่ขาด Binary ไบนารีของ MediaPipe ไปที่ Python 3.11.9
- **[Face_Recognition] ดาวน์เกรด MediaPipe ใน .venv** — ติดตั้ง `mediapipe==0.10.14` แทนการขยับไปที่เวอร์ชัน 1.0.0 ตระกูลโมเดลใหม่ ซึ่งเอื้ออำนวยให้สคริปต์ `webcam_client.py` เรียกใช้งาน `mp.solutions.face_detection` ได้แบบดั้งเดิม 100% โดยไม่ต้องปรับเปลี่ยนโค้ด
- **[CHANGELOG.md] บันทึกการเปลี่ยนแปลงของโครงการ** — ปรับยอดประวัติการดำเนินการแก้ไขโมดูลสภาพแวดล้อมตัวอ่านกล้องของ Face_Recognition ทั้งฝั่ง Frontend และ Backend ของระบบ

## 🔧 ปัญหาที่แก้ไข

- **`AttributeError: module 'mediapipe' has no attribute 'solutions'`** — เนื่องจาก Python 3.14 บน Windows ยังไม่มีล้อติดตั้งสำเร็จรูป (Precompiled binary wheels) ทำให้กระบวนการติดตั้งด้วย pip ได้แพ็กเกจที่ไม่สมบูรณ์และขาดโฟลเดอร์ `solutions` แก้ปัญหาโดยการสร้างสภาพแวดล้อมใหม่และอิงเอนจินหลักเป็น Python 3.11
- **`ModuleNotFoundError: No module named 'numpy._core._multiarray_umath'`** — เกิดจากไฟล์ติดตั้ง `.cp314` ของ numpy ตกค้างและทับซ้อนในโฟลเดอร์ `site-packages` เมื่อสั่งสวิตช์เอนจิน Python มาเป็น 3.11 แก้ไขปัญหาโดยการเคลียร์/ลบโฟลเดอร์ `.venv` ปัจจุบันออกทั้งหมดก่อน แล้วเริ่มติดตั้ง pip สดใหม่
