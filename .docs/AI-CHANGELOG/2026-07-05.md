# Changelog 2026-07-05

## ✅ สิ่งที่ทำเสร็จ

- [notifications] เชื่อม notification flow กับข้อมูล tenant/user จริงเพื่อให้ resolve recipient phone โดยไม่ใช้ค่า hardcode
- [notifications] เพิ่ม notification worker สำหรับประมวลผล pending notifications แบบ polling พร้อม health/metrics endpoint
- [notifications] เพิ่ม dead-letter queue, audit log, provider webhook handler และ endpoint สำหรับดู/Retry/ลบ dead-letter
- [notifications] เพิ่ม API endpoint สำหรับดู audit logs และ dead-letter list
- [tests] เพิ่ม test coverage สำหรับ worker lifecycle, webhook handling และ dead-letter flow

## 🔧 ปัญหาที่แก้ไข

- แก้ปัญหาการส่ง notification ที่ยังใช้ recipientPhone ค่าหลอกใน billing / maintenance / visitor flow
- เพิ่มความสามารถในการตรวจสอบสถานะการส่งและข้อผิดพลาดผ่าน audit trail และ dead-letter
- ทำให้ผู้ดูแลระบบสามารถ retry หรือลบ notification ที่ล้มซ้ำได้ผ่าน API
