# Archive Sprints

โฟลเดอร์นี้ใช้เก็บสรุปความคืบหน้าของแต่ละ Sprint หรือ Milestone ของโปรเจกต์ Smart-Dormitory-Management-System

## รูปแบบการตั้งชื่อไฟล์
```
sprint-XX-summary.md   หรือ   milestone-[name].md
```

## วัตถุประสงค์
* บันทึกสิ่งที่ทำเสร็จในแต่ละ Sprint
* บันทึกการตัดสินใจทางสถาปัตยกรรมที่สำคัญ
* อ้างอิงย้อนหลังเมื่อต้องการทราบว่าระบบถูกออกแบบมาแบบนี้เพราะอะไร

## กฎการใช้งาน
* ไฟล์ใน archive เป็น Read-only reference ห้ามแก้ไขหลังจาก Sprint ปิดแล้ว
* AI Agent อ่านได้เฉพาะเมื่อจำเป็นต้องสืบค้นประวัติการตัดสินใจเท่านั้น
