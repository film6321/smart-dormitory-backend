# ภาคผนวก ก พจนานุกรมข้อมูลตารางในระบบ MEEDEE Dormitory

ภาคผนวกนี้แสดงชื่อคอลัมน์ ชนิดข้อมูล คีย์ และความหมายของข้อมูลในแต่ละตาราง โดยอธิบายหน้าที่ของตารางและคอลัมน์ด้วยถ้อยคำสั้น ๆ

คีย์หลักใช้ระบุรายการ คีย์อ้างอิงใช้เชื่อมข้อมูลกับตารางอื่น และค่าห้ามซ้ำหมายถึงไม่สามารถบันทึกค่าเดียวกันซ้ำได้
