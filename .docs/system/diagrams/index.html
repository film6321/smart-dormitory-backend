04 · System Architecture

เส้นทางเว็บผ่าน Nginx ไปยัง Express, workers และ Socket.IO รวมฐานข้อมูล cache ไฟล์ และ API ที่เชื่อมต่อ

ข้อควรทราบในการใช้ภาพ

  • รูปแสดงหน้าที่และ configuration ที่ตรวจจาก source ไม่ใช่ผลรับรองว่าอุปกรณ์หรือ provider จริงผ่านการทดสอบแล้ว กล้อง ประตู SMS และ provider จริงยังเป็น Out of scope ของรอบ QA
  • ภาพรวมจัดกลุ่มตามงาน ไม่ได้หมายความว่าทุกกล่องเป็น microservice; ภาพสถาปัตยกรรมแสดงโมดูลและ workers ในโปรเซสหลักเดียว
  • ERD แสดงเฉพาะตารางหลัก แต่ครบทุกคอลัมน์ของตารางที่เลือก UK ของ Bill เป็นคีย์ร่วม tenantId + roomId + billingPeriod ไม่ได้ unique แยกคอลัมน์ และ HousingApplicationDraft.roomId ไม่ใช่ FK ใน schema
  • ภาพ ERD มีเส้นอ้อมบางจุดเพื่อหลบตาราง ควรเปิด HTML หรือ SVG เพื่ออ่านชื่อฟิลด์ ไม่ย่อทั้งภาพลงสไลด์เดียวจนตัวหนังสือเล็ก
  • คำอธิบายภาพเป็นภาษาไทย ส่วนปุ่มเครื่องมือของ Archify และภาษาที่ประกาศใน HTML ภาพยังใช้ English fallback ใช้เมนู Export ในภาพเพื่อส่งออกใหม่ได้
  • อ้างอิง source ที่ commit c6897b6a50e7f7074b6d3321691788d92afda1ba; เอกสารฐานข้อมูลและไฟล์ภาพที่เพิ่มในงานนี้ยังไม่ได้ commit และไม่ใช้เป็นหลักฐานแทน source ที่ตรึงไว้
