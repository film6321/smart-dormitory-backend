# บรรณานุกรม

รายการต่อไปนี้รวบรวมเอกสาร กฎหมาย งานวิจัย และเอกสารทางเทคนิคที่อ้างถึงในบทที่ 1–5 และเอกสารประกอบระบบ เรียงแหล่งภาษาไทยตามลำดับอักษร ก–ฮ ก่อนแหล่งภาษาอังกฤษตามลำดับ A–Z หากจัดรูปเล่มตามคู่มือของสถานศึกษา ให้คงข้อมูลผู้แต่ง ชื่อเรื่อง ปี และ URL ให้ครบ แล้วปรับรูปแบบเครื่องหมายวรรคตอนตามคู่มือดังกล่าว
