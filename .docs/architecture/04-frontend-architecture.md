# 04. Frontend Architecture

## Structure

Pages
↓
Components
↓
Hooks
↓
API Service
↓
Backend

## Responsibilities

### Pages

Top-level screens for each feature.

### Components

Reusable UI building blocks.

### Hooks

Encapsulate feature logic, state handling, and side effects.

### API Service

Centralized layer for calling backend APIs.

### Backend

Provides business data and operations for the frontend.
