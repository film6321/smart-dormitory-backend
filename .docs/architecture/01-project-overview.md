## Project Name

Smart Dormitory Management System

## Project Goal

Develop a web-based smart dormitory management system using OCR and face recognition technologies to improve resident management, visitor verification, and identity validation.

## Technology Stack

- Backend: Node.js, Express, TypeScript
- Database: PostgreSQL + Prisma
- Cache/Queue: Redis
- Frontend: React + Vite + TypeScript
- Authentication: JWT
- External Services: OCR API, Face Recognition API

## Scope

- Authentication and authorization
- Resident and room management
- Visitor management
- Billing and payment slip verification
- Maintenance requests
- OCR-based identity document verification
- Face recognition registration and verification

## Main Modules

- Authentication
- Residents
- Rooms
- Visitors
- Billing
- Maintenance
- OCR
- Face Recognition
